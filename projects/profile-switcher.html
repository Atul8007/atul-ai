VS Code extension for Shopify CLI account management

Profile Switcher

Switches the active Shopify CLI account by updating the CLI's currentSessionId config pointer. No token handling. No session manipulation.

What it does

Reads your local Shopify CLI config, lists available accounts, and swaps the active pointer so shopify theme dev targets the right store.

Architecture & Code Snippet

profile-switcher.js 
// Profile Switcher Environment Pointer Swap
function switchShopifyProfile(targetProfileKey) {
  const profileConfig = loadLocalProfileConfig(targetProfileKey);
  if (!profileConfig) throw new Error(`Profile "${targetProfileKey}" not found`);
  
  process.env.SHOPIFY_FLAG_STORE = profileConfig.storeDomain;
  console.log(`[Profile Switcher] Switched active environment to: ${profileConfig.storeDomain}`);
}
