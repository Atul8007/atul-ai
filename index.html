figclaw

AI-powered design-to-development workflow bridge connecting Claude AI directly to Figma.

DESIGN-TO-CODE WORKFLOW

Overview

figclaw is a developer workflow tool engineered to connect Claude AI directly to Figma node graphs prior to official Model Context Protocol (MCP) support. It enables seamless extraction of design tokens, component hierarchies, and visual specs directly into AI prompting contexts.

Problem

Translating complex UI mockups into clean code required developers to manually copy-paste styles, measure pixel distances, and type CSS properties line by line. Existing developer handoff tools lacked direct execution bridges to AI coding assistants.

Architecture & Technical Code

figclaw-bridge.js 
// figclaw API Execution Snippet
async function fetchFigmaNodeContext(fileKey, nodeId) {
  const response = await fetch(`https://api.figma.com/v1/files/${fileKey}/nodes?ids=${nodeId}`, {
    headers: { 'X-Figma-Token': process.env.FIGMA_ACCESS_TOKEN }
  });
  const data = await response.json();
  return parseFigmaNodeGraph(data.nodes[nodeId].document);
}

Profile Switcher

A lightweight Shopify developer workflow tool for switching development profiles/environments.

Private Repository Utility
DEVELOPER WORKFLOW

Overview

Profile Switcher is a specialized developer utility built to simplify managing multiple client Shopify Admin stores and development environments without requiring repetitive manual logouts and credential re-entry.

Problem

Shopify developers working across multiple client stores lose valuable time re-authenticating sessions and navigating between partner accounts. Standard browser session management often triggers unwanted logouts across active tabs.

Architecture & Technical Code

profile-switcher.js 
// Profile Switcher Environment Loader
function switchShopifyProfile(targetProfileKey) {
  const profileConfig = loadLocalProfileConfig(targetProfileKey);
  if (!profileConfig) throw new Error(`Profile "${targetProfileKey}" not found`);
  
  process.env.SHOPIFY_FLAG_STORE = profileConfig.storeDomain;
  console.log(`[Profile Switcher] Switched active environment to: ${profileConfig.storeDomain}`);
}

ShopifyThemeCheck

Overview

ShopifyThemeCheck is an inspection tool engineered for rapid storefront auditing. It automatically parses live Shopify store pages to extract active theme identifiers, third-party app scripts, custom font files, social media integrations, and raw product JSON schemas.

Problem

Auditing a merchant's live storefront to diagnose script bloat, third-party app dependencies, or custom variant structure required tedious manual tracing through DevTools DOM trees and network requests.

Architecture & Technical Code

theme-check-inspector.js 
// ShopifyThemeCheck DOM & JSON Extractor
function inspectShopifyStorefront() {
  const themeData = window.Shopify ? window.Shopify.theme : null;
  const scriptTags = Array.from(document.querySelectorAll('script[src]')).map(s => s.src);
  const productJson = document.querySelector('script[type="application/json"][id*="Product"]');
  
  return {
    theme: themeData,
    installedAppScripts: scriptTags.filter(src => src.includes('apps') || src.includes('cdn')),
    productSchema: productJson ? JSON.parse(productJson.textContent) : null
  };
}
