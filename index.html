Case Study

Optimizing Theme Performance & Liquid Render Time

1

Problem

A high-volume merchant experienced slow page rendering due to redundant Liquid loops and unoptimized asset loading on product pages.

2

Investigation

Analyzed theme render times using Shopify Theme Inspector. Identified repeated `all_products` lookups and un-lazy-loaded hero assets.

3

Technical Approach

Refactored section Liquid logic to utilize native Metafield references, cached array filters, and implemented responsive srcset image loading.

4

Implementation

Rebuilt product gallery sections using pure CSS grid & light JS sliders, eliminating heavy third-party carousel dependencies.

5

Result

Result: Improved mobile Lighthouse Performance score by +35 points and reduced DOM content load time significantly.
